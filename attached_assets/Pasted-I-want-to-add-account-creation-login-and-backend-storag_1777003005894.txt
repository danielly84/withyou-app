I want to add account creation, login, and backend storage to my existing WithYou app.

Context:
WithYou is a warm, supportive mental wellness app that helps people get quick emotional guidance before stressful situations. Right now, users can use the app, write entries, and view some metrics, but the app does not remember who they are or save their previous entries over time. I want WithYou to feel more personal and useful by remembering each user’s past entries, reflections, moods, stressors, and patterns.

Please inspect the existing codebase first and preserve the current visual design, tone, flows, and WithYou voice as much as possible.

Core goals:
1. Add a sign up and login flow
2. Store user entries in a backend database
3. Tie entries and metrics to each signed-in user
4. Let returning users see their past entries and insights
5. Use saved entry data to power the metrics / insights page
6. Keep the experience warm, lightweight, and emotionally safe

Authentication requirements:
- Add a simple sign up flow with:
  - Name
  - Email
  - Password
  - Optional: “What should WithYou call you?”
- Add login with email and password
- Add logout
- Add basic password validation
- Add error states for invalid email, weak password, account already exists, incorrect password, etc.
- After sign up, route users into the main app
- After login, route users into the main dashboard or home screen
- If a user is not logged in, allow them to view the landing page but require login/sign up before saving entries or viewing personal metrics
- If the app currently has anonymous/local entries, add a migration option after sign up:
  “Save my existing reflections to my account”

Backend/database requirements:
Use the best backend option available in this Replit project. If there is already a database, use that. If not, create one using a reliable setup such as PostgreSQL, SQLite, Supabase, Firebase, or Replit’s available database tooling. Do not rely only on localStorage for signed-in user data.

Metrics:

Metrics should support:
- Total entries
- Mood trends over time
- Stress level trends over time
- Most common situations or themes
- Most common tags
- Entries this week / month
- Improvement from mood_before to mood_after
- Improvement from stress_level_before to stress_level_after
- A “What WithYou is learning about you” section

Privacy and safety requirements:
- Because this app may store sensitive emotional reflections, make the data model and UI privacy-conscious.
- Do not expose one user’s entries to another user.
- All user-specific queries must be scoped by user_id.
- Add a simple privacy reassurance during sign up:
  “Your reflections are private to your account and help WithYou personalize your experience.”
- Add a short disclaimer somewhere appropriate:
  “WithYou is not a replacement for professional care. If you’re in immediate danger or crisis, contact emergency services or a crisis hotline.”
- Avoid making medical claims.
- Do not call the app a licensed therapist.
- Use language like “support,” “reflection,” “guidance,” “patterns,” and “emotional check-ins.”

Memory feature:
Build a lightweight memory system that helps WithYou feel like it knows the user over time.

When a user creates a new entry:
- Save the full entry
- Save mood/stress metadata if available
- Update or generate a user-level memory summary
- Track recurring themes, stressors, and helpful coping strategies
- Use this memory to personalize future guidance

Add a “Memory” or “What WithYou remembers” section somewhere in the app, possibly inside the Insights/Metrics page. It should show gentle, user-friendly summaries like:
- “You often come here before high-pressure conversations.”
- “Grounding exercises seem to help when your stress is above 7.”
- “Work uncertainty has appeared in several recent reflections.”
- “You tend to feel better after naming the next small step.”

Make sure the user can:
- View saved entries
- Delete an entry
- Edit an entry if possible
- Clear their memory summary if possible
- Delete their account data if reasonable for this build
